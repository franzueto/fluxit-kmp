- **`FB-102`'s Android adapter is the reference implementation `FB-103` should mirror in shape, not in language** (all in `composeApp/src/androidMain/kotlin/com/fluxit/firebase/auth/`, uncommitted): `AndroidAuthRepository.session` is a `callbackFlow` that (1) emits current state first — deterministically `Unresolved` until resolved, never skips straight to `SignedOut`/`Authenticated`; (2) registers the SDK's native auth-state listener; (3) relays through a private `MutableStateFlow`; (4) `awaitClose { registration.remove(); relay.cancel() }` to guarantee teardown on cancellation; (5) `.distinctUntilChanged()`. State lives in the StateFlow, not the flow itself, so operations with no active collector still leave correct state, and `restoreSession()` can publish `ResolutionFailed` — a state the raw listener callback can never emit on its own (it calls `reload()`/server round-trip so a revoked/disabled/deleted credential doesn't pass silently).
